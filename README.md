# Sinai Seeds - digital contact card (Ali Fayed)

Live: https://sinai-seeds.mo2868417.workers.dev

## Contents
- site/index.html      The whole card: HTML, CSS and JS in one file (no build step). Contains the logo SVG, the vCard generator ("Save contact"), and all 4 languages.
- site/og.jpg          1200x630 link-preview image (WhatsApp/Facebook, 69 KB), referenced by og:image / twitter:image. Shows the real logo lockup and the name Ali Fayed. site/og.png is the old 534 KB version, kept so cached previews still load.
- site/og-preview.html The HTML the og.jpg was rendered from (served live at /og-preview). It uses site/img/logo-lockup.png and the same warm-plate treatment as the card.
- worker/              worker.js + wrangler.toml for Cloudflare Workers (see note below).
- site/img/logo-lockup.png/.webp  The real client logo (three leaves over the "SINAI SEEDS / AGRICULTURAL INVESTMENT / ALI FAYED" sign plate), transparent background, used in the card hero. WebP first, PNG fallback.
- assets/logo.svg      The old vector three-leaf mark, kept for reference only (no longer used in the page).
- assets/make_logo.py  Crops that logo out of a screenshot of Ali Fayed's Facebook post and writes site/img/logo-lockup.png (pillow + numpy).
- assets/contact.vcf   The vCard the "Save contact" button builds (name, company, phone, email, address, Facebook).
- variants/sinai-seeds-2/  build.py generates the same card with every Facebook link removed
                      (social row goes to 3 icons, vCard drops the Facebook URL, page is noindex).
                      Its output in variants/sinai-seeds-2/site is deployed as its own Worker,
                      sinai-seeds-2 (https://sinai-seeds-2.mo2868417.workers.dev), so the live
                      card is never touched. Re-run build.py after any change to site/index.html.
- qr/                  3 QR PNGs for the main card (sinai-qr-A-poster, -B-clean, -C-sticker-round) and the same 3
                      for the second card (sinai-2-qr-*), plus generate_qr.py (needs: pip install segno pillow numpy)
                      and the og source used for the logo cut. Run it as
                      `python3 generate_qr.py [URL] [OUTPUT-PREFIX] [MARK]`; with no arguments it rebuilds the main set.
                      MARK is leaf (the first set, a green leaf on a dark disc), lockup (the real logo on a
                      small dark badge) or free (the real logo straight on a cream knockout, no badge).

## Languages
Arabic (RTL), English, Turkish, Chinese. The switcher flips layout direction for Arabic.

## Deploy
1. cd worker && npx wrangler login   (or set CLOUDFLARE_API_TOKEN yourself with Workers Scripts Edit)
2. npx wrangler deploy
To change the link preview: re-render og-preview.html to a 1200x630 image (keep it under 300 KB for WhatsApp) and replace site/og.jpg. WhatsApp caches previews, so share the link with ?v=2 to test.

## Notes
- No tokens or secrets are included.
- worker/worker.js is a clean reconstruction using static assets, not a byte copy of the script currently deployed (that one inlines the files). Site files are byte copies from the live Worker.
- QR error correction is H; re-run generate_qr.py after changing URL in the script.
